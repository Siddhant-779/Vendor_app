# Vendor_app
#Short Description
Tap2Order:
* Developed a lightweight and contactless ordering solution for small vendors and food corners.
* Each vendor is provided a unique QR code that customers can scan to instantly view the menu on their phone

#1 Purpose 
Purpose The purpose of this document is to cover the overall description of the Software System, Customer Menu & Order Management System (CMOMS) – Tap2Order (Product Name) using the QR Code technology which is a real time ordering system to manage the order process for the restaurant and shops. This doc highlights specifically the system’s functional perspective like hardware, software and communication interfaces, memory constraints, operations, functions, characteristics, constraints, assumptions and dependencies. This SRS also detail the system’s specific requirements or non-functional requirements like performance, design constraints, software system attributes such as reliability, availability, security, maintainability and portability. The SRS will serve as a reference for system engineers, analyst, designer, developers, testers, restaurant administrators, and future system maintainers.
#2 Scope
Food ordering is a very important service for a food store or restaurants. This is a service that offered by the waiter to a customer who came to the restaurants. In the conventional restaurants or food stores, a static menu is utilized to show the available food and beverage choices to customers. There are some problems that may be face by using the traditional food ordering such as: - These menus are generally paper based and therefore impose restrictions on the prices available       and a responsibility to update them in case of discounts or hike. - Misunderstanding between waiter and customer when taking the order - Customer need to wait for a moment for a waiter to come to take order Therefore, the food ordering system using QR Code technology is an alternative to solve this problem. The system uses smartphone as platform. The customer needs to scan the QR Code on the table and confirm their order by doing payment. Besides the staffs can manage menu and view order list. This document specifies the requirements for a restaurant paper menu and ordering replacement strategy to alleviate the problems associated with current method. The tap2Order will: - Allow shops to onboard themselves, create and manage menus, add payment options. - Have dashboard for the shops to view sells, growth, customers reach and all other analytics. - Proper section for the shop to view all the coming and served order requests. - provide ease of ordering food for the customers - Provide secure, role-based access to all users.  
#Product Functions
There are following major functions of the CM0MS software: - Login/Logout. - Place Order. - Pay Bill. - Tracking Order State (Accepted, Processing, Delivered). - Menu Management. - Process Cash Payment. - Reporting and analytics for administrators. 
#User Characteristics
Customers: Limited technical skills, expect mobile-friendly, intuitive UI. - Waiters and Staffs: Moderate technical skills, require efficient workflows. - Admin Staff: Office staff with basic IT knowledge. - System Administrator: IT professional managing security, backups, and maintenance.
